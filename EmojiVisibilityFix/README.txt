Install:
1. Go to Chrome, open: chrome://extensions
2. Turn on Developer mode (top-right).
3. Click "Load unpacked".
4. Select EmojiVisibilityFix.
5. If it doesn't show up in the extension list, try adding it again.
6. Reload the webpage where the emojis were a " [] "

- DO NOT DELETE THE IMAGES OR CHANGE THE NAME OF THEM,
If you want to change the look of the emojis,
the images are:
Face Holding Back Tears: U+1F979.png
Pink Heart: U+1FA77.png
Melting Face: U+1FAE0.png
Salute: U+1FAE1.png
Face With Bags Under Eyes: U+1FAE9.png
Once you change the images, reload the extension.
or
To change what the emojis look like, simply go to EmojiVisibilityFix and change the images to 
whatever you want, reload the extension, then reload the web page containing those emojis.

- to reload the extension, go to open: chrome://extensions and on the extention theres a refresh button.

What it does:
Replaces the emojis unicode with the images

To remove this extension, go to chrome://extensions and click Remove.
